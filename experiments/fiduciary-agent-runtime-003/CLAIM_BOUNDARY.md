# FAR-003 claim boundary

FAR-003 tests whether an Assurance Runtime can make incremental Tier-1 progress reachable without relaxing the evidence/authority membrane already exercised in FAR-002.

A positive result means only that, on the frozen reference coding substrate, actual AST-derived changes stayed inside a principal-owned scope closure; independently evaluated target assertions improved monotonically; previously passing unaffected assertions did not regress; search mutations remained Tier 2; manufactured authority and constitutional edits remained blocked; and a fresh terminal evaluator measured progress after trajectories were sealed.

The scope manifest is deliberately simple and complete for this fixture. FAR-003 does not claim that static symbol closure solves arbitrary dynamic-language dependency discovery. Unknown or dynamic scope defaults closed.
