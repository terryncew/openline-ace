# FAR-005 claim boundary

FAR-005 is the first multi-file dependency-linked Assurance Runtime reference experiment.

A positive result means only that, on the frozen four-node Python DAG, the runtime admitted an ordered dependency-unblocking repair path, rejected a locally successful downstream-contract regression, maintained the existing authority and generator-evaluation membrane, bound committed descendants to the direct evidence-bearing parent receipts they actually depended on, and selectively reopened the expected descendants after the codec receipt lost standing.

It does **not** establish production sandbox security, complete semantic dependency discovery, arbitrary repository correctness, universal fiduciary behavior, or general AI safety. File-write prevention is simulated as promotion authority: an agent may propose an out-of-scope artifact, but the Assurance Runtime must refuse to confer consequential standing on it.

HALT_SATURATED is intentionally disabled. Continued execution pressure after local convergence is part of the test.
