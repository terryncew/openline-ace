# SLD-002 Claim Boundary

SLD-002 is an external historical replay of **review standing**, not a failure predictor.

The strongest allowed positive claim is narrow:

> In the frozen public GitHub corpus, exact-state review standing sometimes resolved `LOST` before a later terminal human disposition, with the preregistered lead-time/coverage tradeoff and less indiscriminate invalidation than the frozen baselines.

It does **not** establish that:

- a `CHANGES_REQUESTED` review predicts technical failure;
- closed-unmerged pull requests are all defective;
- review standing is a complete dependency graph;
- the result transports beyond the frozen repositories or review workflow;
- OLP improves model capability, truth, or runtime safety.
