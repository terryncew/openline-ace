Prospective coding-agent pressure test of the assurance runtime introduced by FAR-001, now using the RGG-002 result to activate a separate generator-mutation lane.

`ordinary code -> task/consequence evidence -> mandate -> Receipt Gate`

`search machinery -> frozen meta evidence -> task/consequence evidence -> mandate -> Receipt Gate`

`tests / evaluators / mandate / receipt verification / Gate policy -> agent has no mutation authority`
