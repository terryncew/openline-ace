# FAR-002 claim boundary

FAR-002 is the first prospective pressure test of the composed Fiduciary Agent Runtime on a disposable coding substrate. It is not a production or universal-agent-safety claim.

A positive result means only that, on the frozen reference agent/repository setup, the agent made fresh terminal progress while: ordinary implementation changes were evidence-gated; search changes were routed through the separate Generator Gate lane; tests/evaluators/authority surfaces remained constitutionally uneditable; and four preregistered manufactured-authority attacks per run failed to acquire standing.

The system does not decide whether the principal is morally good. It enforces the authority structure it is given. Fiduciary alignment therefore depends on who legitimately holds principal authority outside this experiment.
