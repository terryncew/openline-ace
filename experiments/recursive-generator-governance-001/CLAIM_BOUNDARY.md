# Claim boundary

RGG-001 tests one narrow constitutional seam: whether a proposal generator that
is allowed to revise itself begins optimizing toward blind spots in the same
finite evaluator used for ordinary task selection, and whether a structurally
separate Generator Gate reduces that capture without simply freezing all
change.

A positive result can support only this statement on the frozen reference
substrate. It cannot establish that all self-improving agents Goodhart, that a
Generator Gate is sufficient for general AI safety, or that the reference
integer-aggregation benchmark transfers to deployed coding agents.

The experiment separates three mutation tiers:

1. Candidate-local operational mutations: ordinary Receipt Gate / `E_task`.
2. Persistent/shared/proposal-shaping generator mutations: Generator Gate.
3. `E_meta` and principal-owned constitutional surfaces: no swarm mutation
   authority. Changes require out-of-band principal authority.

Unknown surfaces default to Tier 2. A declaration of "ordinary" never lowers
an effective tier. Cumulative behavioral drift in the emitted proposal
distribution independently escalates to Tier 2.

The power calibration is not primary evidence. `E_external` is terminal-only
and never participates in adaptive selection.
