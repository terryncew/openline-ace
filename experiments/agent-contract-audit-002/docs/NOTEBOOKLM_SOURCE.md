# A-002 study source: the microscope leaves the fixture

A-001 proved that the counterfactual audit mechanics could separate a planted
load-bearing dependency from a planted ritual. It intentionally did not claim
external LLM evidence.

A-002 freezes the first blind stochastic proving ground. A real LLM first
produces successful baseline traces. A separate LLM proposer sees only public
trace projections and proposes candidate dependencies. It is denied hidden task
state and verifier logic. A second untrusted mapping step may connect open-text
candidates to a small public intervention catalog, but the executable active,
sham, and restoration semantics are deterministic and frozen.

The audit then runs at least 64 complete baseline/active/sham/restoration pairs
per admitted candidate. Standing is delegated to the exact A-001 grading code,
verified by Git blob identity before import. An independent stdlib-only verifier
recomputes success from the original task bytes and final-output hashes.

The checked A-002 release contains only protocol conformance. No provider run is
fabricated. Its scientific standing remains
`MECHANICS_ONLY_NOT_EXTERNAL_AGENT_EVIDENCE`.

The first live target is deliberately small. An agent must read a three-field
ticket and return its current value. Marker and padding fields travel in every
successful baseline observation, creating plausible ritual candidates. The
proposer is not told that the original verifier depends only on the current
value.

A live result earns `BLIND_EXTERNAL_SEPARATION` only if the current-value
freshness surface is supported and at least one always-present nuisance surface
is rejected as ritual, with zero independent replay mismatches.

This is the first test of the actual contract-microscope claim: not that symbols
beat learning, but that an untrusted model can conjecture broadly while a
separate counterfactual instrument forces each dependency to earn standing.
