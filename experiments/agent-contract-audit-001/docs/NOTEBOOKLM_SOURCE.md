# OpenLine Agent Contract Audit 001 — Study Source

RCDL-001 through RCDL-007 progressively removed reasons to believe an explicit
symbolic relational representation had unique predictive, causal, or active
search utility. The strongest synthetic test still tied the learned baseline on
accuracy and query cost.

A-001 changes the role of the machinery.

The question is no longer whether symbolic RCDL beats learning. The question is
whether an external audit instrument can take a workflow dependency that looks
important and force it to earn causal standing.

The proposed pipeline is:

trace → untrusted candidate proposer → active/sham/restoration intervention →
original verifier → paired stochastic effect estimate → auditable contract
manifest candidate.

The LLM proposer is intentionally untrusted. It may be creative and
open-vocabulary. It may not certify its own clause.

The intervention harness is also untrusted with respect to standing. A wrapper
can manufacture a requirement. Therefore wrapper-local failure cannot prove the
original task needed the rule.

A-001's first checked result is only conformance. It contains a planted
load-bearing artifact-binding relation, a planted scratchpad ritual that is
perfectly correlated with observational success, a generic context perturbation
that hurts both active and sham arms, and a wrapper-manufactured audit-marker
rule.

The correct instrument behavior is respectively:

SUPPORTED, REJECTED_RITUAL, UNDECIDABLE_SHAM_EFFECT, REJECTED_RITUAL.

The external agent lane remains unrun. This is deliberate. No fixture may
promote itself into evidence about real stochastic agents.

The next empirical threshold is a blind run against a real agent workflow with
fresh task identities and the original task verifier. At least one proposed
dependency must survive the active-versus-sham effect margin and restoration,
while at least one highly correlated ritual is rejected.

If that separation cannot be produced, the contract-microscope direction should
stop.

If it can, the output belongs downstream as evidence: Claim Graph can preserve
dependency consequences, Receipt Gate can decide whether a receiver admits the
contract for a particular action, and a separate compiler may eventually turn
receiver-admitted contracts into static OTel monitors or runtime gates.

A-001 itself never grants execution authority.
