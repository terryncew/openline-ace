# DMA-001 Protocol

## Question

Can a pre-registered molecular feature associated with developmental age earn **load-bearing standing** for the old-progenitor fate bias reported in long-lived cortical organoids?

## Source observation versus new causal claim

The source paper establishes developmental-age recording and recall at the cellular/system level. It does not establish a single molecular memory carrier.

DMA-001 therefore starts *after* candidate generation.

Candidate generation is untrusted.

The candidate feature and all analysis rules must be frozen before targeted intervention outcomes are inspected.

## Four-arm design

**Baseline** — establish that the selected assay reproduces the expected old-progenitor fate behavior.

**Matched sham** — impose comparable manipulation burden without disrupting the candidate relation.

**Active perturbation** — weaken or remove the candidate relation.

**Restoration** — reverse or rescue the candidate relation using a pre-specified path.

## Independent oracle

The outcome oracle must be blinded to expected standing and should derive the primary endpoint from donor-resolved cell identity using a frozen cell-type rule or pre-registered classifier.

The grader consumes only final arm outcomes. It does not receive candidate prose, rationale, expected verdict, or source-paper interpretation.

## Promotion rule

A candidate can only become `SUPPORTED_LOAD_BEARING` when:

1. baseline success is above the frozen floor;
2. sham success is above the frozen floor;
3. active perturbation causes a sufficiently larger failure rate than sham;
4. restoration recovers success by a sufficiently large amount;
5. minimum replication is met in all four arms.

Otherwise the grader rejects, abstains, or remains unresolved.

## Boundary conditions

A supported candidate is load-bearing **for the tested assay, perturbation, restoration, cell lines, culture regime, endpoint, and preregistered thresholds**.

It is not automatically necessary in vivo, in all organoids, or across species.

No output carries policy authority.
