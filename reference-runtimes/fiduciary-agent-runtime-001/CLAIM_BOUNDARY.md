# Claim boundary

FAR-001 demonstrates a compositional software contract: proposal generation, independent evidence, consequence evaluation, principal authority, receiver adjudication, receipt dependencies, and standing-loss reopening can remain mechanically distinct in one executable agent runtime.

The included tests establish only the behavior of this reference implementation. They do not establish production security, legal fiduciary status, autonomous-agent safety, distributed revocation latency, cryptographic key custody, or resistance to a compromised operating system.

The coding agent has proposal authority only. Evaluators have evidence authority only within their receipt kinds. The principal owns mandate authority. The receiver Gate owns consequence admission.
